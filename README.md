# agentic-tooling

Skills and agents for Claude Code, and the record of the third-party ones this
setup consumes.

## How it works

Two mechanisms, one script.

**What this repo authors** is symlinked into place. `skills/<name>/` and
`plugins/<name>/` are linked into `~/.claude/skills/`, `~/.agents/skills/` and
`~/.cursor/skills/`; `agents/<name>.md` into `~/.claude/agents/`. Nothing is
copied, so editing a file here takes effect in a running session with no
install step and no lockfile to drift.

**What it does not author** is not vendored. Every third-party skill is an
entry in [`.claude-plugin/marketplace.json`](.claude-plugin/marketplace.json),
pinned to a commit, installed by Claude Code itself, and linked out of its
plugin cache into the two roots that have no plugin mechanism of their own.
That file is the single record of provenance, and `git log -p` on it is the
history of what was accepted and when.

## Using sync.py

```
./sync.py                     # fan out and prune; idempotent, offline
./sync.py status              # link state, plugins, listing budget; offline
./sync.py check               # what moved upstream, filtered to what we consume
./sync.py diff <name>         # that change as a patch
./sync.py update [name]       # accept it: bump the sha, reinstall, relink, commit
./sync.py vendor <name>       # promote an entry to a checked-in copy under vendor/
./sync.py unvendor <name>     # the reverse
./sync.py readme              # regenerate the index below
```

Plain stdlib Python 3, no dependencies. Only `check`, `diff`, `update` and
`vendor` touch the network.

A destination is only written when it is empty or already holds a link into
this repo or the plugin cache. Anything else is reported as a collision and
left alone, so remove it yourself if you want this repo's copy to win.

## Invocation posture

Everything authored here sets `disable-model-invocation: true`. Skills are
invoked by name from the `/` menu and never chosen by Claude on its own.

The reason is the listing budget: Claude Code loads every skill's name and
description into every session, and when that overflows, descriptions are
dropped starting with the skills you invoke least — silent degradation with
`/doctor` as the only signal. Suppressed skills cost nothing, which leaves the
whole budget for third-party skills that genuinely earn being reached for
unprompted. `./sync.py status` reports the running total.

The cost is that a skill written to fire on its own only fires when you type
its name. Skills that turn out to be wanted unprompted get the flag removed one
at a time, checking the budget after each.
